# Web界面使用指南

## 🌟 最新功能

### ✨ Token符号点击跳转（NEW!）

现在可以直接点击Token符号跳转到币安交易页面！

**使用方法：**
1. 访问 http://localhost:8866
2. 在表格中点击任意Token符号（如BTCUSDT）
3. 自动在新标签页打开币安交易页面

**视觉效果：**
- Token符号显示为蓝色可点击链接
- 鼠标悬停时变深蓝色并出现下划线
- 点击后在新窗口打开，不影响当前页面

## 📊 完整功能列表

### 1. 数据统计卡片

显示4个关键指标：

| 指标 | 说明 |
|------|------|
| 符合条件Token | 总共多少个Token符合筛选条件 |
| 平均成交量增长 | 所有Token的平均成交量增长率 |
| 平均价格涨幅 | 所有Token的平均价格涨幅 |
| 最大成交量增长 | 单个Token的最大成交量增长率 |

### 2. 搜索功能 🔍

**位置**: 控制栏左侧搜索框

**使用方法**:
```
1. 在搜索框输入Token符号
2. 实时过滤显示匹配的Token
3. 支持部分匹配（如输入"BTC"会匹配"BTCUSDT"）
```

**示例**:
- 输入 "BTC" → 显示 BTCUSDT, WBTCUSDT 等
- 输入 "ETH" → 显示 ETHUSDT, ETHFIUSDT 等
- 输入 "USDT" → 显示所有USDT交易对

### 3. 排序功能 🔄

**位置**: 控制栏中间下拉菜单

**排序选项**:
- **按成交量增长排序** - 从高到低显示成交量增长率
- **按价格涨幅排序** - 从高到低显示价格涨幅
- **按符号排序** - 字母顺序排列

**使用方法**:
```
1. 点击下拉菜单
2. 选择排序方式
3. 表格自动重新排序
```

### 4. 刷新数据 🔃

**位置**: 控制栏右侧按钮

**功能**:
- 重新从CSV文件加载最新数据
- 更新统计信息
- 刷新数据表格

**使用场景**:
```
当你运行了新的筛选器，生成了新的qualified_tokens文件后，
点击"刷新数据"按钮即可加载最新结果，无需重启服务
```

### 5. Token跳转 🔗 (NEW!)

**位置**: 数据表格Token符号列

**功能**:
- 点击任意Token符号
- 在新标签页打开币安交易页面
- 直接定位到该交易对

**跳转到**:
```
https://www.binance.com/zh-CN/trade/{TOKEN}
```

**支持的操作**:
- 查看实时K线图
- 查看买卖盘口
- 查看成交明细
- 直接下单交易

### 6. 数据高亮 ⭐

**自动高亮规则**:

| 条件 | 高亮效果 |
|------|----------|
| 成交量增长 > 100% | 黄色背景 + 加粗 |
| 价格涨幅 > 10% | 黄色背景 + 加粗 |
| 所有正数据 | 绿色字体 |

**目的**:
快速识别表现优异的Token

## 🔧 自定义选项

### 修改刷新频率

编辑 `simple_web_server.py`，添加自动刷新：

```javascript
// 每30秒自动刷新一次数据
setInterval(refreshData, 30000);
```

### 修改高亮阈值

修改JavaScript代码：

```javascript
// 原来：成交量增长>100%高亮
if (volumeGrowth > 100) volumeGrowthCell.classList.add('highlight');

// 改为：成交量增长>50%高亮
if (volumeGrowth > 50) volumeGrowthCell.classList.add('highlight');
```

### 添加更多排序选项

```javascript
// 在sortSelect中添加选项

// 在sortTokens函数中添加逻辑
```

## 🌐 API使用

### 获取数据JSON

```bash
# 获取所有Token数据
curl http://localhost:8866/api/tokens

# 获取统计信息
curl http://localhost:8866/api/stats
```

### 集成到其他应用

```javascript
// JavaScript示例
fetch('http://localhost:8866/api/tokens')
  .then(response => response.json())
  .then(data => {
    console.log('Token数量:', data.data.length);
    // 处理数据...
  });
```

```python
# Python示例
import requests

response = requests.get('http://localhost:8866/api/tokens')
data = response.json()

if data['success']:
    tokens = data['data']
    print(f"获取到 {len(tokens)} 个Token")
```

## ⚠️ 常见问题

### Q: 点击Token没反应？
**A**: 检查浏览器是否阻止了弹出窗口，允许后重试。

### Q: 搜索不工作？
**A**: 确保JavaScript已启用，清除浏览器缓存后刷新。

### Q: 数据不是最新的？
**A**: 点击"刷新数据"按钮，或重新运行 `token_filter.py`。

### Q: 币安页面打不开？
**A**: 
1. 检查网络连接
2. 某些地区可能需要VPN
3. 确认 binance.com 可访问

### Q: 移动端显示不正常？
**A**: 清除浏览器缓存，使用Chrome或Safari浏览器。
