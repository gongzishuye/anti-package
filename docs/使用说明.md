## 🛠️ 自定义配置

### 修改获取天数

编辑 `run_without_deps.py` 文件，找到这行：
```python
data = fetcher.fetch_top_100_daily_data(days=7, delay=0.2)
```

将 `days=7` 改为你需要的天数，比如 `days=30`。

### 修改请求间隔

将 `delay=0.2` 改为其他值：
- `delay=0.1` - 更快，但可能触发API限制
- `delay=0.5` - 更慢，但更安全

### 获取特定代币数据

```python
# 只获取BTC和ETH的数据
symbols = ['BTCUSDT', 'ETHUSDT']
for symbol in symbols:
    klines = fetcher.get_daily_klines(symbol, days=30)
    print(f"{symbol}: {len(klines)} 条记录")
```
