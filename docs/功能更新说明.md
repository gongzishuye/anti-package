# 功能更新说明 - Token点击跳转

## 🎉 新功能

### Token符号可点击跳转到币安交易页面

现在在Web界面中，点击任何Token符号（如BTCUSDT、ETHUSDT等）都会：
- ✅ 在新标签页打开币安交易页面
- ✅ 直接定位到该交易对
- ✅ 方便快速查看实时行情和交易

## 🎨 界面变化

### 视觉效果
- Token符号现在显示为**蓝色**（#667eea）
- 鼠标悬停时变为**深蓝色**并带下划线
- 鼠标指针变为手型，表示可点击
- 平滑的颜色过渡动画

### 使用方式
1. 打开Web页面：`http://localhost:8866`
2. 在数据表格中找到感兴趣的Token
3. 点击Token符号（如 **BTCUSDT**）
4. 自动在新标签页打开币安交易页面

## 🔗 跳转链接格式

```
https://www.binance.com/zh-CN/trade/{SYMBOL}
```

示例：
- BTCUSDT → https://www.binance.com/zh-CN/trade/BTCUSDT
- ETHUSDT → https://www.binance.com/zh-CN/trade/ETHUSDT
- SOLUSDT → https://www.binance.com/zh-CN/trade/SOLUSDT

## 📱 访问新服务

服务已更新并使用新端口：

```
http://localhost:8866
```

如果是远程服务器：
```

```

```css
.token-symbol {
    font-weight: 600;
```

## 🔧 自定义选项

### 修改跳转链接

如果需要跳转到其他页面（如币安合约交易），可以修改 `simple_web_server.py`：

```javascript
// 现货交易（当前）
const url = `https://www.binance.com/zh-CN/trade/${token.symbol}`;

// 合约交易
const url = `https://www.binance.com/zh-CN/futures/${token.symbol}`;

// K线图
const url = `https://www.binance.com/zh-CN/price/${token.symbol}`;
```

### 修改打开方式

```javascript
// 新标签页打开（当前）
target="_blank"

// 当前页面打开
target="_self"

// 新窗口打开
target="_new"
```

## 📝 注意事项

1. **网络连接**
   - 需要能访问 binance.com
   - 某些地区可能需要VPN

2. **浏览器兼容性**
   - 支持所有现代浏览器
   - 建议使用Chrome、Firefox、Safari

3. **币安账户**
   - 查看行情无需登录
   - 交易需要登录币安账户

4. **安全性**
   - 链接直接跳转到币安官网
   - 不会泄露任何个人信息
