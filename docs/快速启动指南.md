# 快速启动指南

## 🎯 一键启动Web服务

### 最简单的方法

```bash
cd /home/ubuntu/code/anti-package
./start_web.sh
```

然后在浏览器打开: **http://localhost:8000**

---

## 📋 完整使用流程

### 1️⃣ 获取币安数据

```bash
python3 binance_data_fetcher.py
```

这将获取前100个Token的16天日线数据。

### 2️⃣ 筛选符合条件的Token

```bash
python3 token_filter.py
```

这将根据以下条件筛选Token：
- T-1的交易量大于T-2
- T-2是阴线
- T-1是阳线且收盘价大于T-2开盘价

### 3️⃣ 启动Web服务查看结果

```bash
./start_web.sh
```

或

```bash
python3 simple_web_server.py
```

### 4️⃣ 浏览器访问

打开浏览器，访问：
```
http://localhost:8000
```

## 🌟 Web界面功能

### 统计概览
- 📊 符合条件Token总数
- 📈 平均成交量增长
- 💹 平均价格涨幅
- 🚀 最大成交量增长

### 交互功能
- 🔍 **搜索**: 快速查找特定Token
- 🔄 **排序**: 按成交量增长/价格涨幅/符号排序
- 🔃 **刷新**: 重新加载最新数据

### 数据展示
- 详细的T-2和T-1数据对比
- 高亮显示重要指标
- 响应式设计，支持移动端

## 🔧 高级选项

### 修改端口

```bash
# 使用5000端口
./start_web.sh 5000

# 或
python3 simple_web_server.py 5000
```

### 后台运行

```bash
# 后台运行并记录日志
nohup python3 simple_web_server.py 8000 > web.log 2>&1 &

# 查看日志
tail -f web.log

# 停止服务
pkill -f simple_web_server
```

### 查看服务状态

```bash
# 检查服务是否运行
ps aux | grep simple_web_server

# 测试API
curl http://localhost:8000/api/tokens
curl http://localhost:8000/api/stats
```

## 🎯 常见问题

### Q: 页面显示"未找到数据文件"？
**A**: 先运行 `python3 token_filter.py` 生成筛选结果。

### Q: 端口被占用怎么办？
**A**: 使用其他端口，如 `./start_web.sh 8001`

### Q: 如何更新数据？
**A**: 
1. 重新运行 `python3 binance_data_fetcher.py`
2. 重新运行 `python3 token_filter.py`
3. 在Web页面点击"刷新数据"按钮

### Q: 如何停止服务？
**A**: 在终端按 `Ctrl+C`
