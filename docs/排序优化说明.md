## 💡 为什么默认按成交量排序？

### 成交量增长的重要性

1. **资金流入指标**
   - 成交量大幅增长通常意味着资金关注度提升
   - 是市场热度的直接体现

2. **筛选条件核心**
   - 筛选规则第一条：T-1交易量 > T-2交易量
   - 成交量增长是筛选的核心指标

3. **实战价值**
   - 成交量放大的Token更容易产生突破
   - 配合价格涨幅，可以发现强势品种

4. **数据差异明显**
   - 成交量增长范围：3.4% ~ 1699.4%
   - 差异大，排序后更有对比性

## 📝 技术实现

### JavaScript代码

```javascript
// 默认排序方式
let currentSort = 'volume_growth';

// 排序函数
function sortTokens(tokens, sortBy) {
    const sorted = [...tokens];
    
    switch(sortBy) {
        case 'volume_growth':
            // 按成交量增长降序（从大到小）
            sorted.sort((a, b) => 
                b.volume_growth_rate_pct - a.volume_growth_rate_pct
            );
            break;
        // ...其他排序方式
    }
    
    return sorted;
}

// 加载数据时自动应用默认排序
function displayTokens(tokens) {
    const sorted = sortTokens(tokens, currentSort);
    // 渲染数据...
}
```
