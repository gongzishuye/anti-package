## 项目功能总结

### 核心功能

1. **数据获取**
   - 自动获取币安交易量前100的Token
   - 获取每个Token的日线K线数据
   - 时间范围：北京时间每天8:00-次日7:59:59

2. **数据筛选**
   - 根据技术指标筛选Token
   - 支持自定义筛选条件
   - 导出符合条件的Token到CSV

3. **数据分析**
   - 成交量变化分析
   - 价格涨跌分析
   - 技术形态识别（阴线/阳线）

### 主要文件

| 文件 | 说明 |
|------|------|
| `binance_data_fetcher.py` | 完整版数据获取器（需安装依赖） |
| `run_without_deps.py` | 简化版数据获取器（无需依赖） |
| `token_filter.py` | Token筛选器 |
| `test_beijing_time.py` | 时间验证测试脚本 |
| `时间说明.md` | 时间范围说明文档 |
| `使用说明.md` | 完整使用说明 |
| `筛选结果报告.md` | 筛选结果分析报告 |

### 数据时间说明

**重要：** 所有K线数据的时间范围都是：
- 开盘：北京时间 8:00
- 收盘：北京时间次日 7:59:59

这是币安API的默认行为，完美符合中国用户习惯！
