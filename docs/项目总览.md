# 币安Token数据分析系统 - 项目总览

## 📦 项目简介

一个完整的币安加密货币数据获取、分析和可视化系统。

**核心功能：**
1. 从币安获取前100个代币的日线K线数据
2. 根据技术指标筛选符合条件的强势Token
3. 通过Web界面实时展示筛选结果

## 📊 主要功能

### 1. 数据获取 (binance_data_fetcher.py)

**功能：**
- 获取币安交易量前100的USDT交易对
- 获取每个交易对的日线K线数据
- 支持自定义天数（默认16天）
- 数据保存为CSV格式

**K线时间说明：**
- 每根日K线从北京时间早上8:00开始
- 到次日早上7:59:59结束
- 完美符合中国用户交易习惯

**使用方法：**
```python
from binance_data_fetcher import BinanceDataFetcher

fetcher = BinanceDataFetcher()
df = fetcher.fetch_top_n_daily_data(days=30, top_n=100)
fetcher.save_to_csv(df)
```

### 2. Token筛选 (token_filter.py)

**筛选条件：**
1. T-1的交易量 > T-2的交易量
2. T-2是阴线（收盘价 < 开盘价）
3. T-1是阳线（收盘价 > 开盘价）且T-1收盘价 > T-2开盘价

**输出：**
- 符合条件的Token列表
- 详细的T-2和T-1数据对比
- 成交量增长率和价格涨幅

**使用方法：**
```bash
python3 token_filter.py
```

### 3. Web展示 (simple_web_server.py)

**特点：**
- 🎨 现代化设计，紫色渐变背景
- 📊 实时统计数据展示
- 🔍 搜索和排序功能
- 📱 响应式布局，支持移动端
- ⚡ 无需额外依赖

**功能：**
- 统计卡片：总数、平均增长、最大增长
- 数据表格：完整的Token数据展示
- 交互功能：搜索、排序、刷新

**API接口：**
- `GET /api/tokens` - 获取所有Token数据
- `GET /api/stats` - 获取统计信息

# 读取筛选结果

strong_signals = qualified_tokens[
    (qualified_tokens['volume_growth_rate_pct'] > 100) &
    (qualified_tokens['T_minus_1_change_pct'] > 10)
]

# 生成买入列表
buy_list = strong_signals['symbol'].tolist()

## 📝 最佳实践

### 1. 数据获取频率
- **建议**: 每天获取一次
- **时间**: 建议在北京时间早上8点后（新K线生成后）
- **存储**: 保留历史数据文件以便回测

### 2. 筛选策略
- 可以根据实际情况调整筛选条件
- 结合其他技术指标使用
- 建议进行回测验证

### 3. Web服务部署
- **开发环境**: 直接使用 `simple_web_server.py`
- **生产环境**: 建议使用Nginx反向代理
- **安全性**: 添加身份验证机制

### 4. 性能优化
- 大量数据时考虑分页
- 使用缓存减少重复读取
- 定期清理旧数据文件

## 🔒 注意事项

### 1. API限制
- 币安API有请求频率限制
- 程序内置延迟保护
- 如需大量数据，适当调整延迟参数

### 2. 数据准确性
- 数据来自币安官方API
- 但市场数据有时效性
- 建议结合多方数据源

### 3. 投资风险
- 本系统仅供技术分析使用
- 不构成投资建议
- 加密货币投资有风险，请谨慎决策

### 4. 时区问题
- K线时间为北京时间早上8点收盘
- 系统时区可能影响时间显示
- 建议统一使用UTC+8时区
